# 🌱 AI-система экологического мониторинга

Призёр хакатона **Digital Challenge**.

Проект представляет собой систему экологического мониторинга загрязнений с использованием искусственного интеллекта. В рамках проекта мы с командой разработали решение, которое позволяет анализировать изображения и использовать ИИ для получения информации о возможных экологических загрязнениях.

## 🏆 Достижение

🥉 **Призёр хакатона Digital Challenge**

Проект разрабатывался в рамках командного кейса:

> **«Система экологического мониторинга загрязнений»**

## Возможности

- анализ изображений с помощью ИИ;
- выявление информации, связанной с экологическими загрязнениями;
- обработка пользовательских данных;
- взаимодействие с системой через Telegram-бота;
- работа с backend-частью приложения;
- хранение данных;
- веб-интерфейс проекта.

## Использование ИИ

В проекте использовался **GigaChat API** для анализа изображений.

ИИ является частью основной логики проекта: полученное изображение передаётся на анализ, после чего система получает результат от модели и использует его для дальнейшей обработки.
